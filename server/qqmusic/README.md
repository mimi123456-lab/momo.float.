# 一条龙部署 QQ 音乐后端（Render 免费版）

不需要服务器、不需要域名、不需要敲命令。只要一个 GitHub 账号。

## 第一步：注册 Render

打开 https://render.com ，点 **Get Started**，选 **GitHub** 登录并授权（只读权限即可）。

## 第二步：用 Blueprint 一键部署

1. 登录后点右上角 **New +** → **Blueprint**
2. 选择仓库 `mimi123456-lab/momo.float.` → **Connect**
3. 页面会自动读到本目录外层的 `render.yaml`，直接点 **Apply**
4. 等 2~3 分钟，状态变成 **Live**

## 第三步：拿到两样东西

在该服务的页面上：

1. **网址**：页面顶部形如 `https://momo-qqmusic-xxxx.onrender.com`（不要带结尾斜杠）
2. **访问密钥**：左边 **Environment** → 找到 `ACCESS_KEY` → 点复制（这是系统随机生成的）

## 第四步：回到小手机 App

音乐 → 右上角地球 → **我的QQ** → 填网址和密钥 → **保存并连接** → 用手机 **QQ 音乐** App 扫码确认。

看到「QQ 音乐已连接」，歌单和播放就都走你自己的账号了。

## 常见问题

- **第一次打开很慢**：免费版 15 分钟没人访问会休眠，唤醒需要 30 秒左右，属正常。
- **重启后要重新扫码**：免费版磁盘不持久，登录态丢失后重新扫码即可。想一劳永逸，在 Render 的 **Disks** 里加一块 1GB 磁盘挂到 `/data`（约 $1/月），重启就不用再扫码。
- **提示「访问密钥不对」**：注意不要多复制空格，前后要完全一致。
- **某首歌播不了**：版权或 VIP 限制，确认登录的 QQ 音乐账号本身有对应权限。
- **部署失败**：把 Render 的 **Logs** 里报错发我，我按报错修。

> 这个后端保存着你的 QQ 音乐登录态，**网址和密钥不要发给别人**。
